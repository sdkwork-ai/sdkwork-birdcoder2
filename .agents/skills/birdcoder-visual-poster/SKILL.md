# Visual Poster Design

Design a poster that reads in three seconds: concept, hierarchy, system.

## Workflow

1. Fix the brief: purpose, audience, placement (print size or social ratio), and the single action/message.
2. Concept: one dominant visual idea; state it in a sentence before any layout.
3. Hierarchy: headline, supporting line, details, CTA — assign size/weight/position so the eye reads in that order at a glance.
4. System: palette (dominant + accent + neutrals), type pairing, and the margins/grid the layout snaps to.
5. Deliver: layout spec per zone (position, size, copy) and, when generation is requested, a concrete image-generation brief per visual.

## Rules

- Copy is part of the design: cut words before shrinking type.
- One accent color carries attention; everything else supports.
