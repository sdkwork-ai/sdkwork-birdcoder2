# Agent Note: 插件清单页签从瞬时 RPC 故障中自动恢复

Status: implemented

[English](2026-08-16-plugin-inventory-tab-transient-retry.md) | 中文

## Problem

设置中心的“插件列表”页签每次挂载只获取一次 Loader 清单，并把任何 RPC 失败当作终点：页签显示“暂时无法读取插件”，只提供手动重试。瞬时故障——客户端启动期与 remote 命名空间挂载的竞态、HMR 重挂载或连接抖动——会让页面卡在错误态，即使 Host 片刻后已恢复。文案本身承诺“暂时”，死路错误态与页面自己的契约相矛盾。

## Decision

`PluginInventorySettingsTab` 在放弃前自动重试失败的 `list()`：最多两次自动重试，指数退避（500 ms 基数、每次翻倍），之后才落入既有错误态并保留手动重试。自动重试期间保持加载态；手动重试重置重试预算。预算是小型固定产品常量——页面仍保持每次挂载只获取一次、按需获取，手动重试仍是持久故障的最终兜底。

## Alternatives considered

**维持一次性获取加手动重试（现状）。** 拒绝，因为所报告的失败模式本质上是瞬时的；死路错误态要求用户自己发现重试按钮，且与“暂时”文案矛盾。

**无界重试。** 拒绝，因为 Host 侧持久故障（网关被禁用、服务缺失）会让 RPC 无限重放。

**连接重新建立时重新获取。** 拒绝，因为这是为同一结果付出的更大改动：该页签目前不持有连接句柄，有界退避已覆盖同一瞬时窗口。

## Consequences

瞬时失败现在约 1.5 秒内自愈；持久失败仍落入带手动重试的通用错误态。组件测试覆盖瞬时恢复、预算耗尽与同步失败路径。无 wire、DTO 或 Host 改动。
