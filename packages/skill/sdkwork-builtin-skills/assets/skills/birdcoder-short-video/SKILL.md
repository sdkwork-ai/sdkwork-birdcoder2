# Short Video Generation

Produce a finished vertical short, not just one clip.

## Workflow

1. Fix the brief: topic, platform ratio (9:16), duration (default 15–30s), audience, and the closing action.
2. Plan 3–6 shots: one idea each, with a hook in the first shot; write the spoken/on-screen line per shot.
3. Generate each shot with the session's available video generation tools — one concrete, self-contained prompt per shot (subject, action, camera, style, ratio).
4. Assemble in order; note where subtitles, music, or a sound beat attach.
5. Deliver the video plus a one-line summary of what each shot shows.

## Rules

- Keep every shot prompt self-contained: generation tools have no memory of the brief.
- If a shot fails or looks wrong, regenerate that shot only — do not rework the whole plan.
