# Sound Effect Generation

Turn a situation into a generated sound effect.

## Workflow

1. Define the effect: sound source, action, environment (indoor/street/forest), and character (realistic vs stylized/UI-like).
2. State the practical frame: duration (usually 0.5–5s), single hit or loop, and loudness intent.
3. Call the session's available sound generation tool with a concrete one-line prompt; avoid stacking multiple unrelated sounds in one generation.
4. Review for clarity — the sound must be identifiable within the first second.
5. Deliver the asset(s) with name, duration, and suggested placement.

## Rules

- One sound source per generation; layered effects are generated separately and combined.
- Ambience (rain, crowd) says so explicitly and targets loopability.
