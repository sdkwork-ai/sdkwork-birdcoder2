# Poster Generation

Generate a poster visual: concept and copy first, image prompt second.

## Workflow

1. Fix the brief: purpose, audience, channel (print ratio or social format), and the single message/call to action.
2. Write the copy blocks: headline, supporting line, details, CTA — ordered by visual weight.
3. Describe the visual concept in one sentence, then craft the image prompt: composition, dominant colors, style, lighting, and the aspect ratio of the target format.
4. Call the session's available image generation tool; keep copy minimal inside the image (generated text is unreliable) and plan real text as an overlay.
5. Deliver the poster image, the copy sheet, and the prompt used.

## Rules

- The message must survive a three-second glance: one dominant element, one accent color.
- Give the exact ratio with the request (1:1, 9:16, A-series print) — regeneration over cropping.
