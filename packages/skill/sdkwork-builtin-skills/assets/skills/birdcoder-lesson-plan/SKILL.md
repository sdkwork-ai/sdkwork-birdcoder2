# Lesson Plan Generation

Turn a topic and class profile into a teachable lesson plan.

## Workflow

1. Fix the frame: subject, grade level, class duration, prior knowledge, and the number of students.
2. Objectives: 2–4 measurable learning objectives the lesson provably advances; state what students can do by the end.
3. Structure by phases with timing: hook/opening, instruction, guided practice, independent work, and closing/assessment — the timing sums to the class duration.
4. Materials and activities per phase: what the teacher needs, what students do, and the grouping (whole class/pairs/groups).
5. Assessment: the exit ticket or check that tells whether the objectives landed; include differentiation notes for fast and struggling learners.

## Deliverable

One plan per request: objectives, phase table (time, activity, teacher does, students do, materials), assessment, homework.
