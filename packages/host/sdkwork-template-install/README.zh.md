# @deepseek-ai/dsh-sdkwork-template-install

[English](README.md) | 中文

## 概述

`sdkworkTemplateInstall` Remote 命名空间背后的宿主能力，同时服务应用开发脚手架模板的上传与下载两个方向：

- **安装（写入）**：`writeFile` 向操作者选定的目录写入一个常规文件，并按需创建父目录。每次写入都会复查解析后的路径仍位于目标目录之内，拒绝穿越（`..`）、绝对路径、携带 NUL 的名字、Windows 保留设备段以及以点或空格结尾的段；单文件字节上限 64 MiB。浏览器侧负责规划模板安装（下载、解压、筛查见 `ui-sdkwork-deploy` 的 `templateInstall.ts`）并驱动这些写入。
- **发布（读取）**：`listFiles` 遍历项目 `apps/` 下的一个应用根目录，返回全部可打包常规文件及其大小。遍历顺序确定（按名称排序），受文件数与深度上限约束，从不跟随符号链接，并跳过依赖目录、构建产物、版本库内部目录以及 agent/运行时状态。`readFiles` 以 base64 返回其中一批有界文件（64 个文件、32 MiB；单文件时 64 MiB）。浏览器用与本地目录选择相同的 `.gitignore` 感知打包器处理这些字节。

本包不持有任何线上词表，两个方向都由 `sdkwork-template-install-controller` Remote 投影。

## Model Experience

无：该能力只在调用方选定的路径之间移动调用方提供的字节，不产生任何面向模型的内容——没有工具、上下文或 Session 事件。

## 已知限制与后续工作

- 落点约束把解析路径按词法包含在基目录的真实路径之下；不追踪写入目标目录内已存在的符号链接（目录既有内容归操作者所有），打包读取则直接拒绝符号链接而不解析。
- 每次调用写一个文件：大模板意味着每文件一次往返。若模板普遍携带数千个大二进制文件，后续可加分块归档写入动词（begin/push/finish）。
- 打包读取按完整结果设限：最多 20,000 个文件、24 层目录；超限的应用返回 `truncated`，浏览器拒绝发布静默不完整的脚手架。
