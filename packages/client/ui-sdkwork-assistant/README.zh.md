# @deepseek-ai/dsh-client-ui-sdkwork-assistant

[English](README.md) | 中文

## 概述

本插件拥有 `assistant` 应用模式的模式栏条目：首页正下方的「助理」图标，中文下
提示与可访问名称都是「助理」（英文为 `Assistant`）。选中它显示 Bot 团队，选中
其他模式则回到普通智能体表面。

Bot 团队（`ds-bot`）是外壳换肤而不是页面：在 Bot 模式下它遮蔽框架当前会话的
侧边栏与对话单元格。因此 `assistant` 在 `ui-layout` 中是外壳模式——框架保留会
话、左栏、右栏与会话标题——本插件只拥有条目本身，以及把两者绑在一起的那一个
事实。

Bot 插件以 `ctx.botSurface` 发布它的表面选择（一个可观察来源，加一个执行与所有
内部控件同一动作的 setter）。该服务缺席时本插件不贡献任何东西：既没有条目，也
不强制任何表面，因此未组合 Bot 插件的部署既不会出现点不动的「助理」图标，也不
会被锁在无法退出的 Bot 表面里。两个方向都用幂等写入协调，所以无论用户从哪一侧
操作，模式栏与 Bot 插件自带的返回控件都在一步内收敛。

## 运行时要求

需要模式栏条目 slot 契约（`ui-sdkwork-app-modes`）、框架的 `assistant` 外壳模
式与 `ctx.layout.mode`（`ui-layout`），以及来自 `ds-bot` 浏览器半边的
`ctx.botSurface`。该服务是软契约：因为插件是外部包，所以在这里声明；出厂浏览器
半边不再发布它时，bundle 验收用例
（`packages/bundle/web-app/tests/built-in-bot.spec.ts`）会失败。

## 模型体验

无。本插件只渲染面向人的导航入口并切换浏览器视图状态，不进入模型请求、提示词
或会话事件。

#### KV Cache 影响

无。

## 已知限制与后续工作

- **模式与表面是同一个偏好**——同时组合两个插件的 profile 会从首页启动并收起
  Bot 表面；Bot 插件自己记住的表面在挂载时被覆盖。想让 Bot 团队成为落地表面的
  部署应改动框架的默认模式。
- **助理是固定的模式栏条目**——自定义弹窗无法隐藏它。不想在模式栏出现 Bot 团队
  的用户只能去掉插件行。
- **Bot 表面激活时会盖住模式栏**——Bot 模式下插件自己的左列固定覆盖在框架左缘，
  因此「助理」与「首页」条目不可见；回到智能体表面后模式栏恢复（用插件设置里的
  切换控件，或在首页再次点击本条目）。这是 Bot 插件的外壳设计，不是本包的选择。
- **英文文案是通用词**——本地化名称是 `Assistant`，产品词「助理」没有单独的英文
  对应写法。
