# assets/capture/

Capture configuration and evidence root for tablet adaptation.

`tablet/` holds the screenshots and capture notes for every row of
`specs/tablet-adaptation.spec.json`. Capture configuration itself is added with the first
capability package; until then this directory records the required matrix and naming.

Authority: `APP_ASSETS_SPEC.md`, `APP_PAD_ARCHITECTURE_SPEC.md` §5.12 and §11.
