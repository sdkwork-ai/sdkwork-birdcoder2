# assets/media/

Store and catalog source media for `sdkwork-birdcoder2-pad`.

Expected families for this root:

- Primary icon at 1024 x 1024 (PNG, no alpha requirement).
- iPadOS screenshots for the declared iPad display classes.
- Android tablet screenshots for the declared tablet groups.
- Feature graphic / cover media used by the SDKWork catalog.

Media is registered in `../agent.app.config.json` and must use stable CDN URLs. Do not commit
unreviewed binary media without an owning manifest entry.
