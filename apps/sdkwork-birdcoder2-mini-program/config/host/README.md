# config/host/

Platform metadata for `sdkwork-birdcoder2-mini-program`: platform app ids, platform profiles, permission references,
upload environment, platform package settings, and signing **reference** metadata
(`MINI_PROGRAM_APP_ARCHITECTURE_SPEC.md` §10).

Platform-specific behavior belongs in profile adapters such as
`packages/sdkwork-birdcoder2-mp-host/src/weixin/`.
