# config/host/

Capacitor platform and native capability metadata for `sdkwork-birdcoder2-h5`.

Owns iOS bundle id, Android package name, app links / universal links, permission and URL-scheme
references, and signing **reference** names (`APP_H5_ARCHITECTURE_SPEC.md` §2,
`APP_SDK_INTEGRATION_SPEC.md`). Must not contain signing private keys, auth tokens, refresh tokens,
API keys, database credentials, or private service endpoints.
